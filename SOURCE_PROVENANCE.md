Submodule sources are included as ordinary directories so the snapshot is self-contained at source level. Original copyright and license files remain in their directories. The engine uses GPL-3.0; consult upstream/LICENSE and upstream/licenses for component-specific notices.

Local modifications: Android application identity and launcher icon, default JXQY2 launch arguments, native offline guide Activity, popup tool menu, game-thread cheat-menu request route, responsive mobile cheat layout and opt-in battle button captions.

The launcher image was supplied by the user; it is not claimed as generated by this repository. No broad separate license is asserted for that artwork. Original commercial game resources, precompiled dependencies, build caches and private signing material are excluded.

Walkthrough summary sources and limitations are documented in docs/full-walkthrough.md and docs/guide-content.md. No original walkthrough images or downloaded third-party programs are included.
